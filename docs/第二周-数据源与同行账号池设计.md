# 第二周第一天：数据源与同行账号池设计

## 1. 今日目标

今天的目标不是直接写完整自动化代码，而是先建立“白格美宿短视频运营中枢”需要观察的数据地图。

系统未来要做到：

热点/同行内容 → 白格美宿适配评分 → 每日内容推荐 → 发布后数据回收 → 下一次推荐优化。

## 2. 当前限制

当前暂时无法申请到抖音开放平台 hotsearch 权限，所以本周不把 hotsearch 作为核心依赖。

系统采用多数据源适配器方案：

- 本地关键词池
- 同行账号/关键词池
- 抖音指数/巨量算数半自动观察
- 第三方榜单 CSV 导入
- hotsearch 预留接口
- 抖音关键词视频搜索预留接口

## 3. 第一阶段启用的数据源

### 3.1 本地关键词池

作用：围绕白格美宿真实经营场景生成每日观察方向。

关键词分类：

- 核心地域词
- 民宿产品词
- 白格美宿特色词
- 用户需求词
- 内容情绪词

### 3.2 同行账号/关键词池

作用：让系统每天知道应该观察哪些同行方向。

分类：

- 重渡沟民宿同行
- 栾川民宿同行
- 洛阳周边游账号
- 河南避暑民宿账号
- 小院氛围类账号
- 山里农家乐账号

### 3.3 抖音指数/巨量算数

作用：用于观察平台趋势。

当前方式：人工查看，后续导入系统评分。

### 3.4 第三方榜单导入

作用：过渡性获取热门视频、同行内容、行业榜单。

当前方式：CSV/Excel 导入。

## 4. 暂时不启用的数据源

### 4.1 抖音 hotsearch

原因：需要申请权限，当前无法直接使用。

处理方式：保留接口位置，后续申请成功后接入。

### 4.2 抖音关键词视频搜索

原因：需要应用侧配置关键词，当前先作为预留能力。

处理方式：先用关键词池生成观察任务，后续有权限后改成真实接口调用。

## 5. 白格美宿经营目标

系统不是为了炫技，而是服务白格美宿真实经营：

- 降低家人每天想内容的压力
- 更快发现适合民宿的热点
- 更稳定观察同行在拍什么
- 把小院、K歌、烧烤、咖啡、山景这些特色表达出来
- 最终看是否带来咨询和订房
