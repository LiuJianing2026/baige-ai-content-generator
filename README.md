# 白格美宿内容方案生成器

这是一个面向白格美宿真实经营场景的 AI 内容运营辅助工具。

第一版功能：输入目标客群、民宿卖点、当前热点和发布平台，自动生成标题、短视频脚本、镜头清单和朋友圈文案。

## 项目背景

白格美宿在日常内容发布中存在不知道发什么、不知道怎么写、不知道怎么拍的问题。本项目希望通过 AI 帮助家人快速生成可执行的内容方案。

## 技术栈

- Python
- Streamlit
- 大模型 API
- 后续计划加入 SQLite / Supabase
